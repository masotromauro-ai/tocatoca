# features/teoria — la pestaña Teoría

| Archivo | Qué es |
|---|---|
| `TeoriaTab.jsx` | la pestaña y el índice de lecciones |
| `lecciones.jsx` | las seis lecciones (TeoL1 a TeoL6) |
| `piezas.jsx` | las piezas que comparten: grados, notas, figura y secuencia |

Cómo se prueba: `node pruebas/humo.mjs`.
